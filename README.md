# KREA / ROMANCE

Krea2와 커스텀 ComfyUI 파이프라인으로 제작한 여성향 AI 채팅 남성 캐릭터 포트폴리오입니다.

## 작업 구성

- Krea2 Anime v2
- ComfyUI 로컬 생성 파이프라인
- 1024 × 1536 세로형 키 비주얼
- 반응형 갤러리와 이미지 확대 보기

## 프롬프트 구조

Krea2에서는 태그만 길게 나열하기보다 다음 순서의 자연어 지시가 안정적입니다.

1. 용도와 장르: `Premium Korean romance visual-novel character key art for an AI chat app`
2. 성인 명시와 인물 수: `One clearly adult 30-year-old man`
3. 외형과 직업: 머리, 눈, 의상, 소품
4. 표정과 관계성: 첫인상으로 읽혀야 할 성격
5. 구도와 배경: `waist-up vertical editorial portrait`
6. 조명과 완성도: 색조, 광원, 질감, 상업 일러스트
7. 제외 요소: `no text, no logo`

이미지와 캐릭터는 모두 허구이며 성인으로 설정되었습니다.
